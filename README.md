## 🧭 Deliverables

### 📝 Task 1 — Test Design & Risk Coverage

**Directory:** [`task-1/`](task-1/)

Focuses on analyzing requirements, identifying risks and assumptions, and designing test cases to provide appropriate
coverage.

### 🔍 Task 2 — Exploratory Testing & Bug Reporting

**Directory:** [`task-2/`](task-2/)

Documents the exploratory testing approach, observed defects, and supporting evidence.

### 🔌 Task 3 — API Testing

**Directory:** [`task-3/`](task-3/)

**Part A — Postman Collection**

* Collection and environment configuration
* Request validation and test scripts
* Execution results and testing notes

**Part B — API Questions**

* Written responses covering API testing considerations

### ⚙️ Task 4 — Automation Design

**Directory:** [`task-4/`](task-4/)

Presents the proposed automation architecture, design considerations, and a sample Page Object implementation.

### 🚦 Task 5 — Release Strategy

**Directory:** [`task-5/`](task-5/)

Covers release readiness, risk prioritization, go/no-go decision-making, stakeholder communication, and process
improvements.
